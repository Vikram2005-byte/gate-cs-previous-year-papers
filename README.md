# GATE Computer Science Previous-Year Papers

A collection of GATE Computer Science and Information Technology (CS) question papers from 2007 to 2026, organized by year for exam preparation, revision, and practice.

## Paper collection

The archive contains the following 24 PDF files:

| Year | PDF files |
|---|---|
| 2007–2016 | One paper per year |
| 2017 | CS1 and CS2 |
| 2018–2023 | One paper per year |
| 2024 | CS1 and CS2 |
| 2025 | CS1 and CS2 |
| 2026 | CS1 and CS2 |

## File naming

Papers are named by year, for example `2007_CS.pdf`, `2017_CS1.pdf`, and `2026_CS2.pdf`. They are intended to be stored in the `CS/` folder.

## Upload the PDFs

The ZIP archive should be extracted before uploading. Upload the PDF files from its `CS/` folder into this repository's `CS/` directory so that each file can be viewed or downloaded individually.

## Use

These papers are provided as study and practice material. Check the official GATE website for current exam announcements, syllabus, and official instructions.

## Disclaimer

This is an independent student-maintained collection and is not an official GATE website or repository.
