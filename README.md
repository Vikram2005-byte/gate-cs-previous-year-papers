## 🎯 How to use the papers for GATE preparation

1. **Start with a diagnostic test.** Choose a recent paper you have not solved before. Attempt it under timed, exam-like conditions without checking solutions.
2. **Analyse mistakes.** Categorize each lost mark as a concept gap, calculation error, misread question, or time-management issue.
3. **Revise topic-wise.** Revisit the related concept and solve more questions before attempting another full paper.
4. **Keep an error log.** Record the question/topic, why the answer was wrong, the correct approach, and what you will do differently.
5. **Repeat under timed conditions.** Track accuracy, attempted questions, time spent, and recurring weak topics. Do not judge progress from score alone.

## 🗂️ File naming

Use these names consistently:

- Single paper: `YYYY_CS.pdf` — for example, `2007_CS.pdf`
- Multiple sessions/papers: `YYYY_CS1.pdf` and `YYYY_CS2.pdf` — for example, `2026_CS1.pdf`

Keep PDFs in the repository root for now so the links in this index work. The `CS/` directory currently contains a folder note; it is not where the listed PDFs are stored.

## ✅ Archive validation

A small Python script checks that all 24 expected files exist and have a PDF signature. It runs automatically on pushes and pull requests through GitHub Actions.

Run the same check locally:

```bash
python scripts/check_papers.py
```

This check catches missing or incorrectly formatted files; it does **not** confirm that every page is present, that the content is authentic, or that redistribution is permitted.

Contributions that improve the archive are welcome.
